# 🚀 Titan Setup - Landing Page & Vitrine de Conversão

Uma Landing Page moderna e de alta conversão desenvolvida com o conceito visual **Dark + Blue** (fundo escuro e detalhes em azul neon/elétrico). O objetivo principal deste projeto é atuar como uma vitrine de destaque para atrair, reter e direcionar o tráfego qualificado de forma fluida para o seu **site principal** ou plataforma de vendas.

---

## 🛠️ Tecnologias e Recursos Utilizados

*   **HTML5 Semântico:** Estruturação limpa e otimizada para SEO e acessibilidade.
*   **CSS3 Moderno:** 
    *   Variáveis CSS (`:root`) para padronização e facilidade na troca de temas/cores.
    *   Layouts responsivos com **Flexbox** e **CSS Grid**.
    *   Efeitos visuais avançados como `backdrop-filter` (efeito vidro fosco/blur), gradientes radiais, sombras com brilho neon (`box-shadow`) e animações customizadas (`@keyframes pulseGlow`).
*   **JavaScript (ES6+):**
    *   Manipulação de eventos de rolagem (`scroll`) para comportamento dinâmico do cabeçalho.
    *   Escuta e rastreamento de cliques nos botões de conversão (ideal para integração com ferramentas de analytics/pixéis).
*   **Bibliotecas e Recursos Externos:**
    *   **Google Fonts:** Tipografia moderna utilizando a fonte *Outfit*.
    *   **FontAwesome (v6.4.0):** Conjunto completo de ícones vetoriais modernos.
    *   **Unsplash:** Imagens de alta qualidade utilizadas para demonstração na vitrine.

---

## ⚙️ Principais Funções e Seções

1.  **Header Fixo com Efeito Glassmorphism:**
    *   Menu de navegação fluido com âncoras para as seções internas.
    *   Botão de destaque direcionando para o site oficial.
    *   Dinâmica de alteração de opacidade e sombra ao rolar a página.
2.  **Seção Hero (Topo):**
    *   Badge de urgência/oferta por tempo limitado.
    *   Título de alto impacto com efeito visual em neon azul.
    *   Botões de chamada para ação principal (*Call to Action*).
3.  **Vitrine de Produtos / Destaques:**
    *   Grid responsivo de cards com efeito de elevação (*hover*).
    *   Tags visuais de desconto porcentual e selos de "Mais Vendido".
    *   Exibição clara de preços (valor antigo riscado vs. valor promocional atual).
    *   Botões direcionados de conversão (*Garantir Desconto*).
4.  **Seção de Benefícios / Diferenciais:**
    *   Ícones destacados que reforçam a segurança, rapidez e suporte, reduzindo o atrito do cliente antes de ir para o site principal.
5.  **CTA Final e Rodapé:**
    *   Caixa de destaque com efeito de pulsação luminosa para capturar os últimos cliques de conversão.
    *   Links para redes sociais e copyright.

---

## 🔮 Possíveis Melhorias Futuras

*   **Integração com Pixel de Rastreamento:** Adicionar eventos nativos do Meta Pixel (Facebook) e Google Analytics 4 (GA4) para mensurar cliques de saída e conversões em tempo real.
*   **Modo Claro / Escuro Dinâmico:** Implementar um botão de alternância de tema caso queira flexibilidade na identidade visual.
*   **Sistema de Filtros por Categoria:** Adicionar abas na vitrine para filtrar produtos (ex: *Todos, Mais Vendidos, Promoções, Lançamentos*).
*   **Modal de Pré-visualização (Quick View):** Permitir que o usuário abra uma janela modal com mais detalhes do produto antes de ser redirecionado ao site principal.
*   **Carrossel / Slider de Depoimentos:** Incluir provas sociais em formato de carrossel interativo para aumentar a confiabilidade e autoridade.
*   **Internacionalização (i18n):** Adicionar suporte a múltiplos idiomas (Português, Inglês e Espanhol) para expandir o público-alvo.
